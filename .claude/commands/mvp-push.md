---
description: Claude Code 版の成果物を本体（MVP Builder）のプロジェクトへ書き戻す
argument-hint: <projectDir> <projectId | studio の URL> [工程キー ...]
---

`mvp-pipeline` スキルの「8. 本体へ書き戻す」手順を実行してください。

指定: $ARGUMENTS

- **本体側は工程ごとに洗い替える。** 実行前に「どの工程を上書きするか」を列挙して
  ユーザーに提示し、確認を取ってから送る。既存プロジェクトのデータが消える操作なので
  黙って進めない。
- `validate.ts` の警告（工程間の整合性）が出ている場合は、送る前に報告する。
- 書き込み権限つきのトークンが要る。読み取り専用で弾かれたら、ダッシュボードの
  「Claude Code 連携」で「書き戻しを許可する」にチェックして再発行するよう案内する。
  **トークンを応答本文に書かない。**
- 完了したら studio の URL（`<host>/studio/<id>`）を伝える。
